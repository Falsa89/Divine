## 1. Scope & Mandate

This document captures the **design-only** plan to migrate the application
from the current single-shard `user_id`-keyed architecture to a future
multi-server architecture keyed on `(account_id, server_id)`.

**Strictly nothing was migrated, mutated, written, or activated** as part
of SLC-C. The deliverables are:

- 11 JSON design contracts under `/app/data/design/server_lifecycle/`
- 14 Python validators / audits / simulators under `/app/backend/scripts/`
- 1 Markdown report (this file)

## 3. Deliverables — JSON Design Contracts

All under `/app/data/design/server_lifecycle/`:

| File | Purpose |
|---|---|
| `account_entity_schema_v1.json` | Account-wide identity schema (account_id, email, vip, paid wallet refs). Lists forbidden account-wide fields (gold, diamonds_free, equipped_skin, …). |
| `account_wide_document_contract_v1.json` | Contract: documents that MUST be keyed on `account_id` only (users, accounts_wallet_paid*, account_cosmetics). |
| `server_bound_document_contract_v1.json` | Contract: documents that MUST be keyed on `(account_id, server_id, …)` (user_heroes, teams, inventory, gift_transaction_ledger, user_gift_inventory, …). |
| `server_profile_creation_contract_v1.json` | Future `POST /api/server/enter` contract — idempotent on `(account_id, server_id)`. Status: **NOT_IMPLEMENTED_IN_RUNTIME**. |
| `collection_scope_migration_matrix_v1.json` | Per-collection mapping: current_key → target_key, scope, P0/P1/P2, unique/query indexes, backfill source, rollback. 20 collections covered. |
| `multishard_index_plan_v1.json` | 23 indexes (unique + query) per collection. No DB execution. |
| `paid_free_currency_split_plan_v1.json` | Rules: paid Divine Crystals = account-wide; gold/diamonds_free/event currencies = server-bound. Paid balance **never cloned per server** (view-only). |
| `server_aware_route_patch_contract_v1.json` | Required patterns for future server-aware routes; `do_not_implement_routes_now=true`. |
| `single_to_multishard_migration_phase_plan_v1.json` | 13 phases (0–12). Phase 11 (remove legacy fallbacks) marked `reversible=false` and `requires_explicit_user_approval=true`. |
| `slc_c_multishard_rollback_plan_v1.json` | Snapshot + per-strategy rollback per phase; AF2-N preservation explicitly checked. |
| `slc_c_multishard_preflight_result_v1.json` | Generated by `audit_slc_c_repo_multishard_preflight.py` (read-only repo scan). |
